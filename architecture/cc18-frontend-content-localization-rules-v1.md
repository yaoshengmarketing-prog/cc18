# CC18 前台內容在地化規則 v1

狀態：`approved-v1`  
適用範圍：CC18 前台人物名稱、文章標題與卡片顯示文字

## 1. 基本原則

1. 來源名稱與前台顯示名稱必須分離保存。
2. 前台顯示以台灣繁體中文為目標，但名稱正確性優先於全面中文化。
3. 平假名、片假名不得由 AI、程式或編輯自行猜測成漢字。
4. 沒有可靠繁中名稱時，前台保留經查證的日文原名。
5. cc18.tv 人物 stable ID 使用 `cc18.tv:actor:{s_tid}`；數字 ID 必須與 `actor` 命名空間一起保存。
6. 姓名正字修正、顯示名稱更新或藝名變更不得產生新人物；應在同一 stable ID 下保存別名。
7. 來源原名及來源關係文字不得被繁中顯示名稱覆寫。
8. `MovieCardV1` 不負責翻譯、轉字或名稱查證，只顯示上游已核准的投影結果。
9. 搜尋可以使用已驗證或有來源紀錄且標為可搜尋的別名；任何別名都不得僅因可搜尋而成為正式顯示名稱。
10. 缺少可靠顯示名稱時使用明確 fallback，不得顯示「待補」或生成推測譯名。

## 2. 人物資料權責

- Source Record 保存 cc18.tv 當次觀察到的 `actor + s_tid + source_name + source_url`，是來源人物關係的權威。
- `data/localization/performers-zh-tw.json` 保存經核准的日文藝名、繁中顯示名、別名與查證狀態。
- Movie Master 保存來源關係的必要投影，並另外保存前台已解析完成的顯示投影。
- 前台元件不得讀取來源標題猜測人物名稱，也不得自行查名稱字典。

前台人物名稱解析順序：

1. `display_name_zh_tw`
2. `name_ja`
3. Source Record 的 `source_name`

## 3. 別名規則

- 每個 alias 必須標示類型、驗證狀態及是否可用於搜尋。
- 官方舊藝名或經可靠台灣市場來源確認的名稱，可以在核准後標為可搜尋。
- 未核准成正式繁中顯示名，不等於不可搜尋。只要中文寫法可由既有來源作品標題或 Source Record 追溯，即可標為 `SOURCE_TITLE_ALIAS`、`SOURCE_ATTESTED`、`searchable: true`、`display_as_primary: false`。
- `SOURCE_TITLE_ALIAS` 必須保存支持該寫法的來源作品或 Source Record reference；搜尋命中後必須回到原有的 `cc18.tv:actor:{s_tid}`，不得建立第二個人物。
- 來源標題別名不得被輸出為卡片主要姓名，也不得自動升級為 `display_name_zh_tw`。
- 純 AI 推測且沒有來源紀錄的候選，才標為不可搜尋。
- 未驗證候選不得被輸出為 `display_name_zh_tw`。

## 4. 人物名稱搜尋契約（下一階段接線）

- 未來人物搜尋索引必須同時收錄 `display_name_zh_tw`、`name_ja`、`source_name`，以及 `aliases` 中所有 `searchable: true` 的名稱；null、空字串與不可搜尋別名不得進入索引。
- 查詢必須支援名稱內的連續部分文字比對，不得只接受完整姓名。例如 `ねる`、`音琉` 與 `星空` 都必須能命中星空ねる的既有人物紀錄。
- 不同名稱欄位或多個別名命中同一人物時，結果必須以 stable actor ID 合併；同一人物不得因日文名、繁中名或來源標題別名而重複出現。
- 部分比對只影響檢索召回，不改變主要顯示名稱，也不得把來源別名升級為 `display_name_zh_tw`。
- 本規格目前只定義資料語意與驗收契約；正式 `/search/` 尚未接入人物字典。人物索引建立、查詢排序與搜尋結果 UI 是下一階段工作，不得宣稱已在網站上線。

最低驗收案例：

| 查詢 | 必須回傳的 stable actor ID |
| --- | --- |
| `星空ねる`、`星空音琉`、`ねる`、`音琉`、`星空` | `cc18.tv:actor:54454` |
| `一ノ瀬ラム`、`一之瀨蘭` 及兩者的連續部分文字 | `cc18.tv:actor:27185` |
| `柚木れんか`、`柚木蓮花` 及兩者的連續部分文字 | `cc18.tv:actor:29885` |
| `柊もみじ`、`柊紅葉` 及兩者的連續部分文字 | `cc18.tv:actor:54025` |

## 5. 標題欄位權責

- `source_title`：來源站原始作品標題，只保存來源事實，不因語言或文案品質修改。
- `article_title`：讀者可見文章主標題，可經編輯修正為自然繁中，但不得改寫來源事實。
- `display_short_title`：列表與卡片專用短標題；與文章主標題分離，缺值時依既有 fallback 顯示。

任何一個顯示欄位的修改，都不得回寫或覆蓋 `source_title`。
