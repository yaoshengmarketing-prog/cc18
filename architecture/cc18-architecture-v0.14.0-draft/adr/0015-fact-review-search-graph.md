# ADR-0015：事實、影評與搜尋內容圖分離

- 狀態：Accepted
- 日期：2026-08-26

## 決策

每個作品頁由三個互不取代的資料層組成：

1. **作品事實層**：番號、來源片名、可驗證日文原名與翻譯、演員、日期、片商、系列、片長、畫質、來源 Tag、封面及 CC18 URL。資料由 SourceRecord／Registry 提供，AI 不得重寫、推測或覆蓋。
2. **原創影評層**：以公開資料與本機分布式影片 Evidence 為依據的評論、切角、差異與適合觀眾。每項影片觀察必須引用 Evidence，不能宣稱未執行的完整逐幕觀看、對白或音訊分析。
3. **搜尋決策層**：回答使用者在選片時尚未被前兩層直接回答的問題，包括快速判斷、節奏／結構摘要、系列差異、相似作品及其推薦理由、適合與不適合條件，以及可索引 Hub 關係。

Renderer 在建置時依 `movie_id` 與內容雜湊合併三層。Writer 只擁有影評與搜尋決策欄位的寫入權；事實層若衝突，一律以已驗證 SourceRecord 為準並阻擋發布。

## 搜尋原則

- 作品頁承接番號、片名與「番號＋演員」等精確意圖。
- 演員、系列、正式 Tag、最新作品與月份 Archive 承接集合意圖。
- 搜尋／篩選參數頁不自動索引；只有有獨立說明、足夠作品與固定 URL 的策展 Hub 可索引。
- 大量 AI 改寫來源資料、關鍵字堆疊、無差異 FAQ 與只有卡片清單的薄 Hub 均不得發布。
- 站內推薦必須保存 `reason` 與關係類型，不能只靠相同 Tag 隨機串接。

## 結果

完整影片資訊仍是每頁必備內容，但不消耗 Writer token 生成。AI 成本集中在新增決策價值的內容；資料更正不需要重寫整篇影評，影評改版也不會污染來源事實。
