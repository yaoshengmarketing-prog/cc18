# ADR-0012：多層作品名稱與標題身分

狀態：Accepted  
日期：2026-08-26

## 情境

CC18 來源標題常是繁中關鍵詞與劇情敘述，日文正式片名則可能承載作品原始身分。臺灣讀者通常不會用完整日文片名閱讀或搜尋，但直接丟棄原名會失去作品識別；反過來把日文原名當成繁中頁面的 H1，也無法清楚服務讀者與搜尋意圖。

## 決策

來源原文、日文正式片名、繁中直譯、文章 H1、SEO 標題與社群 Hook 分別保存。日文正式片名必須來自可驗證來源；沒有來源時保存 `null`，不得由中文反向翻譯。所有生成標題由二至四項可追溯 `title_signals` 驅動，並保存訊號類型及來源欄位。

顯示、SEO 與社群標題均保留番號。顯示標題至少自然包含兩個訊號；社群標題至少包含一個。作品 URL 只依番號建立，任何標題改版都不改 URL。

## 後果

- 原始身分、搜尋與點擊文案可以各自最佳化而不互相污染。
- AI 標題可被程式稽核，不再依賴特定作品的硬編碼詞彙。
- 缺少日文原名不會阻塞發布，但不得以推測值填補。
- 現有文章需補上 `socialTitle` 與 `titleSignals`，並重新產生內容核准雜湊。

## 回滾

前端可以暫時只顯示 `display_title`，但來源身分欄位與番號 URL 不移除，以避免資料遺失及網址變動。
