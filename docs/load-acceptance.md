# 250 部合成負載驗收

`npm run load:synthetic` 是 Phase 4 的本機、零外送驗收。它不連線 cc18.tv、Cloudflare 或 AI，也不建立文章與媒體。

每次執行會在系統暫存目錄建立一次性 Queue，並驗證：

- 250 部完整 Metadata 全量收件。
- 每部同時建立 Editorial 與 Media Analysis，合計 500 個工作。
- 相同作品再次收件不會增加工作。
- 10 個 worker 可分配工作。
- 過期 lease 可回收。
- 暫時錯誤可 retry 並完成。
- 250 部可規劃為五個、每波最多 50 部的發布波次。
- 結束後刪除一次性 Queue，不保留合成資料。

這項測試通過，只代表容量與狀態機的離線門檻通過。正式排程仍需完成連續七天 draft-only 驗收，並涵蓋至少一次真實來源更新；不得因本測試通過而自動開啟發布。
