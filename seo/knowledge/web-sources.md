# 網路補充資料指南（v1）

用途：補「來源檔沒有、但對選片有幫助」的公開事實（演員其他作品、片商／廠牌、系列沿革、發售資訊、片長）。不補露骨內容，不補私人資訊。

## 身分欄的權威來源
- 番號、演員、片商、系列、發行日、sourceTitle：以 data/source-records/<ID>.json 為準，網路資料不得覆蓋。若網路資料與來源檔不一致，維持來源檔，並在 evidence 記一筆「外部資料不一致」供人工檢查。
- 演員顯示名依 data/localization/performers-zh-tw.json，不從假名推漢字。

## 可查的公開來源（依可信度）
1. 片商／廠牌官方作品頁（例如 S1、MOODYZ、IDEA POCKET 等官方站）：發售日、收錄時間、系列、導演。
2. FANZA（dmm.co.jp）商品頁：品番、発売日、収録時間、出演者、メーカー、レーベル、シリーズ。
3. 演員所屬事務所或本人官方公開頁：活動狀態、出道年（只寫公開資訊）。
4. 粉絲整理的維基類網站：只能交叉核對，不可作為唯一依據。
不使用：盜版站、論壇八卦、需要登入才能看的內容、任何個人隱私。

## 如何標註
- 每個補充事實在 data/review-quality/<ID>.json 的 evidence 加一筆：來源網址、讀取日期（UTC+8）、引用的欄位與值。
- 正文寫法：「片商官方頁列出收錄時間約 120 分鐘」，並在資料來源一行帶過；不要把外部資料寫成本站實看結論。
- 找不到就寫「來源未提供」，不要推測或編造（片長、系列、共演、年齡、出道年都一樣）。

## 禁止
- 不得捏造或推測任何事實、數字、平台內部編號。
- 不得用外部資料推論演員真實年齡、私生活。
- 不得補寫露骨內容描述。

## 資料收集清單 v1（2026-11-29）

寫稿前逐欄收集。只寫已核實或標明狀態的內容；不確定就標「待確認」並留下還要查的來源，不准捏造。查核日期用台灣時間（UTC+8）。本清單做法已核實；個別作品的新事實仍要先對公開頁核對，才能寫進正文。

### 來源優先順序

1. 片商／廠牌官方作品頁（事實來源）：日文原題、演員日文署名、人物頁羅馬字、各版発売日與該版收錄時間、監督、官方系列欄。部分片商站用一般爬蟲會回 403，可改瀏覽器 UA 再試；仍失敗則標「本次未能讀取」。
2. 事務所官方人物頁（事實來源）：出道年月、出道片商。出道作番號與該作發售日，改以出道作的片商作品頁為準。
3. FANZA／DMM 商品頁（事實來源，能讀到時）：配信開始日、數位片長與規格。因地區限制或年齡牆讀不到正文時，標「本次未能讀取」，不可改猜日期類型。
4. 實體通路商品頁（如駿河屋）：只作交叉確認，不得單獨覆寫片商官方欄位。本次讀不到就略過，不影響已核的官方值。
5. 維基、論壇、彙整站：只能找線索，不可當唯一依據。

不使用：盜版站、論壇八卦、需要登入才能看的正文、任何個人隱私。身高、三圍若要寫，只可引用片商或事務所已公開的欄位，並放在女優頁；不得推算真實年齡。

身分欄（番號、演員中文顯示名、片商來源名稱、來源檔發行日、sourceTitle）仍以 `data/source-records/<ID>.json` 為準，網路資料不得覆蓋來源檔。外部日期與來源檔不一致時，另列帶「版本＋日期類型」的欄位，並在 evidence 記「來源有歧異」，供人工決定前台怎麼顯示。不要把兩個日期混成一個「發行日」，也不要用官方日期直接覆寫來源檔。

### 欄位、來源與抓不到時怎麼寫

| 欄位 | 來源優先 | 抓不到時怎麼寫 |
|---|---|---|
| 番號（含有無連字號的寫法） | 來源檔；片商品番對照 | 沿用來源檔番號。對照寫法未核實就只記線索，不改網址或標題番號。 |
| 日文原題 | 片商作品頁標題 | 寫「日文原題來源未列」或「本次未能讀取」，不要自譯回填。 |
| 演員日文署名、羅馬字 | 片商作品頁出演欄、人物頁 | 中文顯示名維持 localization，不從假名推漢字，也不從中文反推日文或羅馬字；缺的欄位留空。 |
| 日本 DVD／BD 發售日、該版片長 | 片商作品頁對應版本欄 | 分欄留空並寫「來源未列」。來源檔已有日期時仍保留原值，另標日期類型。 |
| 配信開始日、數位片長／規格 | FANZA 商品頁（能讀到時） | 「本次未能讀取」或「來源未列」。不可把 DVD 發售日或來源檔日期改標成配信日。 |
| 導演署名 | 片商「監督」欄 | 「來源未列」。同導演其他作須該作官方頁確認。沒有官方點名、獎項或其他可核對依據，不得稱「代表作」，只寫「同導演其他作品」。 |
| 官方系列 | 片商「シリーズ」欄的正式名稱 | 欄位空白就寫「官方系列欄未列」。不可因番號相近或題材相似而自造系列。本站可另建題材分類，但須標明是編輯分類，不是官方系列。 |
| 出道作、出道年月、出道片商 | 事務所頁＋出道作片商頁 | 查到月份就寫到月，不要補日。專屬起日與迄日分開保存，缺一端就留空。 |
| 比較作品 | 先站內候選，再以雙方片商頁核對 | 必須寫出會讓讀者做不同選擇的具體差異。只能說「同一片商」就降低順位或不用。對方官方頁有資料即可引用，不必先有站內空頁。 |
| 查核紀錄 | 與每個事實一併保存 | 記來源網址、原頁欄名、原始值、查核日期、狀態（已核實／來源未列／本次未能讀取／來源有歧異）。一次抓取失敗時，保留上次已核值與查核日，不得清空舊值。 |

比較作品的驗收：編輯讀完後，要能指出本片與最接近的另一部，在什麼地方會讓讀者做出不同選擇。事實歸事實（官方欄位原文），本站編輯分類（例如「穿搭企劃」）要分開標註，避免寫成片商官方系列。
