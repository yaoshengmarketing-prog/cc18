# CC18 編輯知識庫（seo/knowledge）

每小時 cc18-editorial 與平行補寫線開工時必讀。內容只教「怎麼把選片評析寫好」，不涉及任何刪除、下架或網站結構變更。

| 檔案 | 用途 |
|---|---|
| good-examples.md | 抽查高分範例與好在哪裡 |
| common-mistakes.md | 常見錯誤、反例與改法 |
| web-sources.md | 可用的公開資料來源、如何標註、不可捏造 |
| CHANGELOG.md | 每輪抽查後的更新紀錄 |

規則優先序：prompts/review-writer.md 與 prompts/review-critic.md ＞ 本知識庫。兩者衝突時以 prompts 為準，並在下一輪抽查時修正本知識庫。
不經手清單（data/editorial-exclusions/）中的作品不得作為範例，也不補寫、不重寫。
